## 性能の要約(docs/PERFORMANCE.md より)

条件: Mac17,3 / 32GB / macOS 27 / **Debug 構成・テストホスト内・画面外描画**、合成 JPEG(12MP・24MP)。単発計測で ±10% 未満は誤差。Release や実 GUI での計測はなし。

- ソフトブラシ 1 セグメント(4000×3000): 30.9ms → 0.11ms
- 50本の長い斜めストロークのアンドゥ保持: 2124MB → 247MB
- 24MP JPEG のコールドオープン(中央値): 234ms → 155ms
- 表示デコード 12MP: 31ms(キャッシュ命中 0.06ms)、24MP@5120px: 131ms(命中 0.07ms)
- 20枚ステップ(12MP): 先読みなし 33ms/枚 → あり 0.24ms/枚
- 30枚ステップでのメモリは頭打ち(キャッシュ上限 512MB)
- 6000×4000 キャンバス: +183MB
- 4000×3000 の全再合成: 1レイヤー 1.5ms / 2レイヤー 3.0ms
- `main()` → `applicationDidFinishLaunching`: 約 130ms(Debug、テストホスト内のみ。プロセス起動・ウィンドウ表示を含まない)

## 検証の区分

### 自動テストで確認(139 テスト合格)

- 保存の安全性(開く・表示・モード切替・編集で原本を書かない、別名保存で原本不変、読み取り専用先の失敗)。
- 各形式の読み込み、EXIF 向き、色空間、PNG/JPEG 往復、`.dpp` 往復、自動保存と回復(手動 `autosave()` 呼び出し)。
- ツール動作(ペン/ブラシ/消しゴム/塗り/スポイト/図形/テキスト/選択/切り抜き)、アンドゥ、レイヤー、変換。
- ナビゲーション、ソート、先読み、シャッフル、メタデータ表示。
- 設定の既定値・範囲・永続化、ローカライズの網羅、メニューのキー重複なし。

### 実機GUIで確認(スクリーンショットによる。確認済みの事実のみ)

- Finder 式オープン(`open -a`)で1ファイル → Photo ウィンドウ1つ、空キャンバスなし。
- 同じファイルをもう一度開いても重複しない。
- 3ファイル → 1ウィンドウ・1セッション。
- 壊れたファイル → エラーアラート。
- 単独起動 → 1920×1080 白キャンバスの Paint ウィンドウ。
- ⌘E で Photo → Paint、ズーム 100% を維持。
- 日本語 UI とダークモードがライブウィンドウで正しく表示。
- フォルダアクセスのバナーが表示されること(許可フローの完了までは未確認)。

### 未検証で実機確認が必要

マウスによる実描画、日本語 IME 入力、印刷パネル、スライドショーのフルスクリーン、Finder とのドラッグ&ドロップ、サンドボックスのフォルダ許可フロー(許可→再起動後の再利用)、強制終了後のクラッシュ回復、Dock 再アクティブ化、Intel 実行、ツールバーの回転ボタン、GIF 再生、共有パネル、設定ウィンドウ、タブ/ウィンドウ復元、各アラート(統合警告等)。

## 手動テスト手順(未検証項目)

事前: Release ビルドを起動。テスト用に、同じフォルダへ画像を5枚程度(PNG/JPEG/GIF を含む)用意。

1. **テキストツールの日本語 IME 入力**
   1. 起動して Paint を開く(空キャンバス)。`T` キーかパレットの「あぁ」を選ぶ。
   2. キャンバスをドラッグして枠を作る。
   3. 日本語入力に切り替え「にほんご」と入力 → 変換候補が出る間(下線の未確定文字列)に `p` `b` などを入力しても **ツールが切り替わらない** こと。Space で変換、Return で確定。
   4. 確定後、枠外をクリック → 文字がレイヤーに描画され、`⌘Z` で1回で消えること。
   5. 変換中に Esc / ⌘Z を押しても未確定文字列が壊れないこと。
2. **マウス描画**
   1. ペン(`P`)で速くドラッグ → 線に途切れがないこと。ブラシ(`B`)・消しゴム(`E`)も確認。
   2. 25%・100%・400% のズームで、描いた位置とカーソル位置が一致すること。
   3. 図形(`U`)を Shift/⌥ 併用でドラッグ、塗りつぶし(`G`)、スポイト(`I`)、選択移動、切り抜きを実行。1操作=1回の `⌘Z` で戻ること。
   4. 可能ならペンタブレットで筆圧を確認。
3. **印刷**
   1. 画像を開き `⌘P` → 印刷パネルが開き、プレビューに画像が用紙内で中央・縦横比維持で表示されること。
   2. `⇧⌘P` のページ設定で用紙の向きを変えてプレビューが追従すること。PDF として保存して内容を確認。
4. **スライドショーのフルスクリーン**
   1. 複数画像のフォルダで1枚を開き(フォルダアクセスを許可)、`⇧⌘F`。
   2. フルスクリーンになり、約5秒ごとに切り替わること。Space で一時停止/再開、Esc で停止しフルスクリーンも解除されること。
   3. 設定でシャッフル・ループ・ディゾルブを変えて再確認。編集済み(未保存)の画像では開始されないこと。
5. **Finder とのドラッグ&ドロップ**
   1. Photo モード: Finder から画像1枚をウィンドウへドロップ → 同ウィンドウで表示。複数枚ドロップ → 1セッション。
   2. Paint モード: ドロップ → 「Insert into Canvas / Open as New Image / Cancel」シート。⌥ を押しながらのドロップは直接挿入。複数枚で挿入した場合に最初の1枚だけが使われること(既知の制約)も確認。
   3. 画像がウィンドウに収まっている Photo モードで画像をデスクトップ/Finder へドラッグアウトできること。
6. **フォルダアクセスのバナーフロー**
   1. サンドボックスの外にあるフォルダの画像を Finder から開く → 「Allow access to this folder…」バナーを確認。
   2. 「Allow…」→ そのフォルダを選択 → ← → で同フォルダの他画像に移動できること。
   3. アプリを終了して再度同じフォルダの別画像を開き、バナーが再表示されず前後移動できること(bookmark の再利用)。File > Allow Access to Folder… からも許可できること。
7. **強制終了後のクラッシュ回復**
   1. 設定で「Keep recovery copies of unsaved work」がオンであることを確認。Paint で複数レイヤーに描き、保存せず約 15 秒以上待つ。
   2. Activity Monitor か `kill -9` でアプリを強制終了。再起動。
   3. 書類が回復されレイヤーが保たれていること、**元の画像ファイルが変更されていない**こと(更新日時・内容)を確認。
8. **Dock 再アクティブ化**
   1. ウィンドウをすべて閉じて Dock のアイコンをクリック → 新規 Paint キャンバスが開く。
   2. ウィンドウを最小化して Dock のアイコンをクリック → 最小化ウィンドウが復帰し、新規ウィンドウは増えない。
   3. ウィンドウ表示中に他アプリから Dock のアイコンをクリック → 何も壊れずに前面に来る。
9. **その他(任意)**: ツールバーの回転ボタン、共有ボタン、GIF アニメ再生と Paint での警告、設定ウィンドウの操作と言語切替の再起動、ウィンドウ復元、Intel Mac での起動。
