# 実装済み機能一覧

コード監査の結果に基づく一覧です。状態は **実装済み** / **一部実装(partial)** / **仕様との差異(deviation)** で示します。「検証」欄は、実機GUIで確認したのか、自動テストか、コードレビューのみかを示します(詳細は [TEST_RESULTS.md](TEST_RESULTS.md))。

## 1. 起動・ウィンドウ

| 機能 | 状態 | 検証 |
|---|---|---|
| Finder からファイルを開く → Photo モード、フィット表示、空キャンバスなし | 実装済み | 実機(open -a 相当、1ファイル) |
| 引数なし起動 → Paint(既定 1920×1080 白、サイズ・背景は設定可) | 実装済み | 実機 |
| 実行中に開いても作業を破棄しない / 同一ファイルは重複しない / 複数ファイルは1セッション | 実装済み | 実機(重複なし、3ファイル1セッション)+テスト |
| 壊れたファイルでエラー表示 | 実装済み | 実機 |
| Dock 再アクティブ化(最小化ウィンドウの復帰、ウィンドウなしなら新規 Paint) | 実装済み | コードレビューのみ |
| 小ウィンドウでのパネル自動折りたたみ(インスペクタ <760pt、パレット <560pt) | 実装済み | コードレビューのみ |
| 複数ウィンドウ / タブ / フルスクリーン / ウィンドウ復元 | **一部実装**: 複数ウィンドウはテストあり。タブは AppKit 自動タブに依存し未テスト。復元は AppKit の NSDocument 復元 + `NSQuitAlwaysKeepsWindows` に依存し未検証 | コードレビュー |
| モード判定にタイマー/スリープを使わない | 実装済み(AppKit コールバックと run-loop 合流のみ) | コードレビュー |

| レイアウト | ツールパレットは既定でキャンバス上部の横一列リボン(ツール・メイン/サブカラー・基本色 20 色パレット・AI 編集メニュー)。設定 > Paint > ツールパレットの位置 で左側(縦)にも戻せる(v0.1.0)。ツールバーに切り取り/コピー/貼り付けボタンはなく Edit メニューのみ | テスト(リボン表示/切替) |
| AI 編集(v0.1.0、macOS 標準のオンデバイス処理・ネットワーク不要): 背景を削除(Vision の被写体マスクで作業レイヤーの背景を透明化)、被写体を新規レイヤーにコピー、自動補正(Core Image) | 実装済み。各1回のアンドゥ。メニュー: イメージ > AI 編集、Paint ツールバー、リボン、右クリック。被写体が無い画像は警告。選択範囲は無視して画像全体に適用 | テスト(実写真で背景透明化・アンドゥ・競合検出) |
| キャンバス: 新規、キャンバスサイズ(3×3 アンカー)とリサイズを分離 | **一部実装**: 新規キャンバスのダイアログ(⌘N。サイズ・プリセット・白/背景色/透明/カスタム背景。起動時の自動無題キャンバスはダイアログなし)。キャンバスサイズシートに縦横比固定なし(リサイズシートにはあり)。1辺最大16384、総ピクセル数上限あり | テスト |
| ペン: 幅、色、不透明度、筆圧(タブレット時)、Shift+クリックで直線 | 実装済み | テスト(実タブレットは未検証) |

| 消しゴム: アルファ消去、背景色モード(背景レイヤー) | 実装済み(不透明度は常に1) | テスト |
| 塗りつぶし: 連続/全体、許容差 0〜255、エッジ AA、バックグラウンド実行 | 実装済み | テスト(巨大キャンバスの待ち時間は未計測) |

| レイヤー: 追加/削除/名前変更/並べ替え/表示/不透明度/複製/下と結合/統合、背景レイヤー、書き出し時に統合 | 実装済み(ブレンドモードなし。レイヤーが1枚なら削除不可) | テスト |

## 4. 共通

| 機能 | 状態 | 検証 |
|---|---|---|
| ドラッグ&ドロップ(取り込み) | **一部実装**: Photo では1ファイルは同ウィンドウで移動、複数は1セッション。Paint ではシートで「キャンバスに挿入 / 新規画像として開く / キャンセル」(⌥ドロップで直接挿入)。**挿入は最初の1ファイルのみ**。標準 .copy カーソル以外のハイライトなし | コードレビュー(Finder 実機未検証) |
| クリップボード | **一部実装**: 貼り付け、新規レイヤーとして貼り付け、新規画像として貼り付け(⌥⌘V)、クリップボードから新規(⌥⌘N)、スクリーンショット貼り付け、大きい貼り付け時のキャンバス拡張確認。プレーンテキストからキャンバス上にテキストボックスは作れない。最初の画像のみ使用。Photo モードでは貼り付け不可(新規画像として貼り付けは可) | コードレビュー |
| 印刷(⌘P、ページ設定 ⇧⌘P) | **一部実装**: 統合画像を印刷領域に縦横比維持でフィット。独自の拡大率オプションなし(システムパネル任せ)。向きは NSPrintInfo | 印刷ビューのテストあり。**印刷パネルは実機未検証** |
| 共有(macOS 共有) | 実装済み(Photo ツールバー、File > Share…) | コードレビュー |
| 外部変更・削除の検知(変更なしの書類のみ自動再読込、編集中は再読込しない、削除でバナー) | 実装済み | コードレビュー |
| エラー処理(欠損・読めない・壊れている・非対応・0バイト・巨大画像) | 実装済み | 壊れたファイルは実機。0バイトや権限なしの個別テストなし |
| 保存失敗 | **一部実装**: システムのエラーテキストを表示(ディスクフル専用メッセージ・テストなし) | テスト(読み取り専用先) |
